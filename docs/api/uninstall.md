# `installer.uninstall`

Two-phase uninstallation support for installed wheel distributions.

Planning never modifies the filesystem. The returned plan lists every RECORD-
declared file, generated bytecode considered for removal, directories that can
become empty, and the reason that a path is retained.

Path traversal, symlink escapes, modified files, unsigned RECORD entries, and
files also claimed by another distribution are handled conservatively. Applying
re-plans first and refuses to run if the filesystem changed.

## Example

```python
from installer.uninstall import apply_uninstall, plan_uninstall

plan = plan_uninstall(
    "venv/lib/python3.12/site-packages/example-1.0.dist-info",
    allowed_install_roots=[
        "venv/lib/python3.12/site-packages",
        "venv/bin",
    ],
)

for file in plan.files:
    print(file.action, file.path, file.reason)

if not plan.blocked:
    result = apply_uninstall(plan, staging_directory="recovery-area")
    print(result.removed_files)
    print(result.failures)
```
